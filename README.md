# 3인분 Windows 개발판 배포

이 저장소는 Windows x64 설치 파일과 업데이트 목록을 배포하는 용도입니다. 앱 개발 소스 저장소·계정·업무 자료는 공개하지 않습니다. 프로그램 실행에 필요한 앱 코드는 설치 파일에 포함됩니다.

## 설치와 업데이트

- 최초 한 번은 Releases의 `saminbun-setup-버전-x64.exe`를 내려받아 설치합니다. 기존 ZIP 실행본은 종료하고 설치하세요.
- 이후 앱의 로그인 화면 또는 **서버 연결 → 프로그램 업데이트**에서 **업데이트 확인**을 누르면 새 버전을 확인하고 다운로드합니다.
- 다운로드가 확인되면 **재시작하고 적용**을 선택합니다. 저장·수집 중인 작업을 마친 뒤 재시작하세요.
- 설치와 업데이트는 기존 앱 데이터 삭제를 요청하지 않습니다. 업무 기록은 중앙 서버에 있으며, 업데이트 파일은 업무 데이터베이스와 분리하여 배포합니다.

## 개발판 주의사항

이 채널은 배포자 코드 서명이 없는 개발판입니다. Windows의 게시자 신원 검증을 통과했다는 뜻이 아니며 최초 실행 시 보안 경고가 나타날 수 있습니다. 보안 기능을 끄거나 경고를 우회하도록 안내하지 않습니다.

업데이트 전송에는 HTTPS와 파일 해시 검증을 사용합니다. 실제 Windows 설치·업데이트 검수 여부는 각 릴리스 설명을 확인하세요. 상용 서명된 정식 배포와는 구분합니다.

계정 비밀번호·주문 내역·인증키 등은 이 공개 저장소나 이슈에 올리지 마세요.
